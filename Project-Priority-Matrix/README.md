# Project Priority Matrix

## Project Overview

The **Project Priority Matrix** is an Excel-based decision-making tool used to prioritize projects based on their **Feasibility, Impact, and Size**.

The tool helps management compare multiple projects and determine which projects should be given immediate attention and which can be considered later.

## How It Works

Each project is evaluated based on three criteria:

- **Feasibility** – How practical or achievable the project is
- **Impact** – The potential business impact of the project
- **Size** – The scale of the project

The projects are then positioned in four categories:

- **Quick Wins** – High-priority projects that can be implemented relatively easily
- **Major Projects** – High-impact projects that require significant effort
- **Nice To Have** – Useful projects that can be considered after higher-priority work
- **May Be Later** – Lower-priority projects that can be postponed

The bubble size represents the **project size**, while the position of each project helps compare its priority.

## Business Use

The matrix helps management:

- Compare multiple projects
- Identify high-priority projects
- Focus resources on projects with greater business value
- Decide which projects should be implemented now or later

# AtliQ Hardware – Sales & Finance Report

## Project Overview

AtliQ Hardware is a hardware manufacturing company that sells products such as laptops, keyboards, mouse, and networking devices to customers like 
Amazon and Croma, and across different countries.

The objective of this project is to transform raw sales data and create Sales and Finance reports for management to monitor business performance.

## Tools Used

- Microsoft Excel
- Power Query
- Power Pivot

## Data Transformation & Data Modeling

- Transformed and cleaned the raw data using Excel Power Query.
- Loaded the transformed data into the Excel Data Model.
- Created relationships between tables using Power Pivot.
- Built a data model to support the Sales and Finance reports.

## Sales Report

The Sales Report helps management monitor:

- Sales performance by customer
- Year-over-year sales growth
- Sales performance across markets/countries
- Target vs. actual performance

This allows management to review sales performance and identify areas that require further discussion or investigation.

## Finance Report

The Finance Report provides management with a view of:

- Total Sales
- Cost of Goods Sold (COGS)
- Gross Margin
- Gross Margin %
- Monthly and quarterly financial performance

This helps management monitor revenue, costs, and profitability and discuss changes in financial performance during business reviews.
